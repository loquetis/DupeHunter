How DupeHunter keeps your files safe

  • Nothing is ever deleted permanently. Selected files go to the Windows Recycle Bin, so you can restore them.
  • Nothing is selected for you. The Keep newest / oldest / largest buttons only tick boxes. You still confirm in a dialog before anything moves.
  • DupeHunter will not let you select every copy in a set: one is always kept.
  • Before moving a file it checks that the file has not changed since the scan, and that the copy you keep still exists.
  • Files on network or USB drives are left alone because they usually have no Recycle Bin.
  • Windows, Program Files, ProgramData and AppData are skipped unless you switch that on.
  • Shortcuts, junctions and hard links are not followed or counted as copies.
  • Similar photos are found by comparing a small fingerprint of each picture. Always look at the thumbnails: a crop or a burst shot can look alike but still be different.
  • Everything stays on this PC. The scan list is only kept in memory.
